# Models

Place Spandrel-compatible weight files here (`.pth`, `.pt`, `.ckpt`, `.safetensors`).

These binaries are **gitignored** so the repo stays clone-friendly. GitHub rejects files over 100MB.

## Suggested default

Download **4xLSDIRDAT** from OpenModelDB and save it as:

```text
models/4xLSDIRDAT.pth
```

Model page: https://openmodeldb.info/models/4x-LSDIRDAT

You can also use the app’s **OpenModelDB** tab or **Models → Import model**.

For GitHub Releases, attach the `.pth` (or a zip) to the release assets so users of the Setup/Portable builds get weights without cloning.
